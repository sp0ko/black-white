black$white
A simple Python game wgere the computer randomly chooses a color: **white** or **black**.
The player tries to guess the correct color. The program tracks poinsts, winning streaks, and saves
results in a ranking file. This project includes both a terminal and a simple GUI version.

##features
-guess the color
0-track points and streaks
-save results to a ranking file
-available in terminal and GUI version

##howto run
clone the repository or download is a ZIP

The game automatically creates a stat.json file in the game folder to store user statistic.
